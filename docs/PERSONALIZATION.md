# Optional ChatGPT Personalization paragraph

This paragraph is optional. It can affect ordinary Chat as well as Work, so do not add it if you want the behavior limited strictly to local Work tasks. The installer never changes Personalization automatically.

> Be concise and outcome-first. Avoid narrating routine actions or repeating my request. Use the fewest tool calls and smallest outputs that preserve correctness, verification, blockers, and requested detail. Prefer focused searches and bounded reads over broad dumps. When local tool output has been compacted, trust its receipt and retrieve only the exact evidence needed. Preserve important decisions and current state across long tasks, and give a short final result without a ceremonial recap.

The installed `~/.codex/AGENTS.md` managed block supplies the Work-specific equivalent without requiring this app-wide setting.

Personalization changes response style only. It does not activate the desktop
bridge, affect ordinary Chat routing, or replace installation and hook trust.
